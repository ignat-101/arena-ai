# TON Trace — визуализатор транзакций TON + AML-аналитика

Сайт/веб-приложение (готов к Telegram Mini App) для отслеживания транзакций кошельков TON:
граф связей как в tonviewer-визуализаторе, реальные данные через **TonAPI (tonapi.io)**,
база сущностей (биржи, сервисы, подозрительные адреса) с админкой, AML-риск-скоринг.

## Возможности

- **Поиск кошелька** — адрес (raw `0:…` или friendly `UQ…`/`EQ…`) или домен `.ton` (`7288.ton`), автодополнение по TonAPI.
- **Граф связей** — канвас-визуализация: узлы = контрагенты/сущности, рёбра = переводы (направление, объём).
  - колесо — зум, перетаскивание — панорама, клик по узлу — детали, двойной клик — открыть адрес.
  - сущности из базы объединяются в один узел (все адреса Binance → узел «Binance»).
- **Фильтры**: период (всё/1Д/7Д/30Д/90Д/180Д/1Г), минимальная сумма, направление (вход/выход), тип актива (все/TON/жетоны).
- **Транзакции**: список событий с пагинацией «загрузить ещё», **всплывающее поп-ап окно** при клике на операцию
  (шапка с направлением и суммой, участники из/в с кнопками «Открыть», список действий, хэши, ссылки на Tonviewer), экспорт CSV.
- **Поп-ап узлов графа**: клик по любому узлу-контрагенту открывает всплывающее окно с деталями
  (объёмы, риск, адрес, кнопки «Открыть в графе» / Tonviewer / TonAPI / админка).
- **PDF-AML-отчёты**: кнопки «📄 Отчёт» (в тулбаре), «📄 Скачать PDF-отчёт» (в панели AML) и «PDF-отчёт по адресу»
  (в поп-апе транзакции). Сервер формирует полноценный отчёт (pdfkit + кириллические шрифты DejaVu):
  шапка, адрес, шкала риска с сигналами, статистика, сущности, топ контрагентов, таблица транзакций с разбивкой на страницы, подвал-дисклеймер.
- **AML-риск**: оценка 0–100 (низкий/средний/высокий/критический) с сигналами: сущности, scam-флаги, домены-клоны, объёмы, возраст кошелька, чёрный список.
- **Админка** (`/admin.html`):
  - регистрация по **мастер-коду** (первый суперадмин) или по **коду-приглашению** (выдаёт суперадмин);
  - роли: суперадмин / админ / аналитик;
  - CRUD сущностей (тип, риск 0–100, статус, теги, описание, список адресов);
  - **импорт сущностей из TonAPI** по названию (whitelist-адреса бирж и их клоны) — одним кликом;
  - AML-кейсы (открыть из визуализатора, менять статус);
  - журнал действий (аудит).

## Быстрый старт

```bash
cp .env.example .env   # заполните ключи
npm install
npm start
# откройте http://localhost:8080
```

Переменные окружения (`.env`):

| Переменная | Назначение |
|---|---|
| `PORT` / `HOST` | порт и адрес (по умолчанию 8080 / 0.0.0.0) |
| `TONAPI_KEY` | ключ TonAPI (https://tonapi.io/dashboard) — используется сервером для прокси |
| `PUBLIC_TONAPI_KEY` | если задан — ключ будет передаваться из браузера напрямую в TonAPI (ключ виден в коде страницы!) |
| `ADMIN_MASTER_CODE` | мастер-код первого суперадмина (смените!) |
| `DATA_SOURCE_MODE` | `auto` (браузер → TonAPI напрямую, при сбое → сервер) или `backend` (всегда через сервер) |
| `MAX_EVENTS_DEFAULT` / `MAX_EVENTS_CAP` | ограничения выборки событий |

## Архитектура и путь к своим lite-серверам

```
Браузер ──▶ TonAPI (tonapi.io) напрямую        [режим auto, быстро]
    └────▶ /api/ton/* (сервер, с TONAPI_KEY)   [фолбэк / режим backend]
```

Источник данных определяется автоматически (индикатор в шапке):
«TonAPI напрямую (браузер)» / «через сервер» / «источник недоступен».
Если TonAPI недоступен — в интерфейсе есть кнопка демо-режима.

**Переход на свои lite-серверы** подготовлен: серверный слой данных (`server/ton-client.js`) — единственная
точка обращения к TonAPI. Чтобы заменить источник на свои lite-серверы, реализуйте те же методы
(`account`, `events`, `jettons`, `search`) поверх вашего lite-клиента (например, через `@ton/ton` +
`ton-lite-client`) и переключите `DATA_SOURCE_MODE=backend` — фронтенд и AML-модуль не изменятся.

## Структура

```
server/
  index.js          — Express: статика + API
  config.js         — конфигурация (.env)
  db.js             — SQLite (node:sqlite): сущности, админы, коды, кейсы, аудит
  ton-client.js     — клиент TonAPI (кэш, rate-limit) — точка замены на lite-серверы
  aml.js            — AML-скоринг (сигналы, оценка 0–100)
  report.js         — генерация PDF-отчётов (pdfkit, шрифты DejaVu в server/assets/fonts)
  assets/fonts/     — шрифты DejaVu (кириллица)
  auth.js           — сессии, scrypt, роли
  address.js        — raw/friendly адреса TON
  seed.js           — сид сущностей при первом запуске
  routes/api.js     — /api: health, config, entities, ton-прокси, aml/analyze
  routes/admin.js   — /api/admin: auth, сущности, коды, импорт, кейсы, аудит
public/
  index.html        — визуализатор
  admin.html        — админка
  js/ (main.js, api.js, graph.js, ton-utils.js, admin.js)
  css/style.css
data/
  aml.db            — SQLite (создаётся автоматически, в .gitignore)
  seed/entities.json — стартовые сущности (проверенные адреса Binance/Bybit/OKX из whitelist TonAPI)
scripts/
  smoke.mjs         — автотесты фронтенда (jsdom)
  smoke-admin.mjs   — автотесты админки
```

## Тесты

```bash
npm test
```

Тесты запускают сервер на :8080 (должен быть запущен) и проверяют: загрузку страницы, демо-режим,
граф, фильтры, транзакции, AML-панель, аутентификацию админки, CRUD сущностей.
